# Student Management System

A Student Management System developed using PHP, MySQL and Bootstrap.

## Features

- Admin Login
- Add Student
- View Student
- Edit Student
- Delete Student
- Attendance Management
- Result Management
- Photo Upload
- Dashboard Analytics

## Technologies Used

- PHP
- MySQL
- Bootstrap 5
- HTML
- CSS

## Installation

1. Install XAMPP
2. Copy project to htdocs folder
3. Start Apache and MySQL
4. Import database
5. Open:
   http://localhost/student-management-system
